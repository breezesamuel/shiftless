# 调研规划（阶段 2）

决定"抓什么"取决于用户目标。抓错了，后面全错。这三类目标各自对应不同 URL 集合。

## 目标 A：竞品/市场调研（"分析竞品""市场在哪""谁在卖"）

抓清单（每个竞品取 2-4 页，3-8 个竞品）：
- 竞品**首页**：主打卖点、口号、目标客户线索
- 竞品**定价页**（/pricing）：定价结构、价值锚点、free tier 存在与否
- 竞品**博客**（/blog 首页）：最近在写什么主题 = 他们在向谁做内容获客
- 竞品**关于页**、**职位页**（/careers）：团队规模、是否融资扩张信号
- 行业榜单/评测页：第三方视角（G2、Capterra、Product Hunt、目标市场本地榜单）

## 目标 B：渠道调研（"从哪获客""哪个平台有效"）

抓清单：
- 目标平台的**落地页/官方文档**：流量规则、扶持期、典型玩法
- 用户比价的聚集地：就是你的客户逛的地方——行业论坛、问答站（知乎/Reddit/Quora）、社群
- 竞品在该渠道的**公开账号主页**：粉丝量、更新频次（用浏览器抓，被反爬降级为搜索快照）

## 目标 C：客户情报（"用户想要什么""他们抱怨什么"）

抓清单：
- 竞品产品**评论区**、**评价页**（Trustpilot/App Store/G2 等）
- 行业**问答帖子**：用户提问 = 需求信号；抱怨 = 竞品的弱点
- 竞品 changelog/release notes：他们补了哪些功能（你没做的空档）

## 通用规则

1. **宁可少而准，不要多而杂**。10 个高质量页面 > 50 个垃圾页面。语料差 → 检索差 → 方案差。
2. 每个 URL 一个说明注释，写进 `corpus/urls.txt`（`#` 开头的行是注释）。
3. 抓不到（403/空页）就**标注 DATA GAP**，不硬闯、不编造。
4. 被抓取时尊重 robots.txt 与频率限制，`--sleep 0.5` 起步。
5. 用户给了竞品名字但没网址 → 用 web search 找官网 URL，再进抓取清单。
6. 抓完先自己扫一眼 corpus，判断是否需要补抓。数据不全就先补，别急着生成。
