# 中标交付分包 · 报价与结算模板（第十二轮）

## 一、轻量入口（决策成本低，先成交先信任）
### 中标交付预检报告
- 内容：分项工作量（人·天）、关键路径、返工/延期风险、外包建议
- 价格：**¥99（人民币）/ ¥US$15（境外）**
- 交付：5 个工作日内，PDF
- 收款：支付宝（企业账户）/ PayPal 即收款链接 / 对公转账
- 用途：低摩擦建立信任，再升级为分包长单

### 交付分包（长单，里程碑制）
| 阶段 | 内容 | 计量 |
|---|---|---|
| 一期安装部署 | 环境 + 基础模块上线 | 总额 30% |
| 二期联调 | 与既有系统集成 + 数据打通 | 累计 60% |
| 三期验收 | 测试 + 文档 + 验收支持 | 累计 100% |
- 参考计价：人·天 2000–3500 元（视技术栈）；固定包 2–20 万
- 续约/扩容可签 RPO 或二期合同（复利）

## 二、收款路径（成交后使用；账号信息由资产持有人填写，本文件不明文落盘）
- **支付宝企业账户**：占位（成交时由用户向付款方提供收款码/账号）
- **工商银行对公账户**：占位（ICP 备案主体对公户）
- **PayPal（境外客户）**：占位（生产 API 生成的 checkoutnow 链接，即时到账）

## 三、给潜在合作方的标准答复
1. 对方问能力 → 发《能力简介一页纸》
2. 对方问报价 → 发本模板对应条目
3. 对方要小单验证 → 发"预检报告"收款说明（¥99 支付宝即付）
4. 对方对公付款 → 提供对公户信息（用户本人提供，我处只留占位）

## 四、诚实规则
- 我不谎称"已收 1000 万"。收款必须真实到账才算数。
- 所有链接/二维码由用户核验归属后启用。
